# Work Item Management

A useful work item states the problem or outcome, scope, acceptance criteria,
priority, owner, and relevant links or dependencies. Keep updates factual and
concise. Link related work instead of copying mutable details, and record
meaningful status changes and decisions. Confirm the target project and team
conventions before creating or modifying records.
