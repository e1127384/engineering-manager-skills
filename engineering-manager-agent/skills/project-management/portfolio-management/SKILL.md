# Portfolio Management

1. Use the organization context and verified project records as the portfolio
   source of truth; identify unknowns instead of filling them with assumptions.
2. Consolidate project outcomes, quarterly backlog priorities, sprint forecasts,
   milestones, squad capacity, and area-path ownership.
3. Surface dependencies between projects with an accountable owner, needed-by
   date, impact, and escalation path.
4. Resolve prioritization or capacity conflicts with the relevant project
   managers; escalate decisions outside delegated authority to the CEO.
5. Report evidence-based status, material risks, forecast changes, and decisions
   needed. Keep project-specific commitments with their owners.
