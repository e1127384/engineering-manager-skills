# Dependency Tracking

For each dependency, identify the providing team or owner, required deliverable,
needed-by date, current status, and impact if delayed. Confirm the dependency
with its owner, track it in the agreed system, and establish a fallback or
escalation path for material risks. Revisit dependencies when scope or timing
changes.
