# Backlog Management

1. Connect proposed work to an outcome, user need, or operational obligation.
2. Clarify scope, acceptance criteria, owner, priority, and dependencies.
3. Split oversized work into independently reviewable and deliverable items.
4. Remove duplicates and stale entries only with appropriate owner agreement.
5. Revisit ordering as evidence, risk, and capacity change; record key decisions.
