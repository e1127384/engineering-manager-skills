# Project Status Report

Report the goal, current state, recent progress, next milestones, and decisions
needed. Use explicit dates and link to source work items or dashboards. Separate
completed facts from forecasts, highlight changes since the prior report, and
state owner and mitigation for each material risk or blocker. Avoid unsupported
percent-complete estimates.
