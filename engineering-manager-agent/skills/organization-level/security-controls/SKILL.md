# Security Controls

1. Retrieve the current organization-approved security controls and identify
   which apply to the project, repositories, and release.
2. Link applicable controls to the relevant work items and release work item;
   identify an accountable owner and verifiable evidence for each requirement.
3. Confirm required reviews, tests, and approvals from authoritative project
   policy and pipeline evidence. Do not infer completion from a successful build
   or deployment alone.
4. Escalate missing evidence, failures, exceptions, or proposed waivers to the
   designated security authority; do not waive controls or disclose sensitive
   findings beyond authorized audiences.
5. Preserve traceability across repository pipelines and environment
   promotions, and report only verified control status.
