# Solution Intent

1. Retrieve the current organization-approved solution intent and its owner;
   do not invent or restate intent from memory when the source is unavailable.
2. Link project work and release work items to the relevant intent record.
3. Check proposed scope and implementation against the stated outcome,
   constraints, and acceptance criteria; record material alignment questions.
4. Escalate conflicting priorities, changed outcomes, or unresolved scope
   alignment to the accountable owner before changing commitments.
5. Preserve traceability from the intent to project work items and release
   evidence without copying mutable source content.
