# Go Observability

- Start from operational questions and the signals needed to answer them.
- Follow existing instrumentation and telemetry conventions.
- Record structured, contextual events at meaningful boundaries; avoid secrets
  and high-cardinality or sensitive labels.
- Measure service health and important dependencies with actionable signals.
- Propagate trace context across supported boundaries.
- Verify instrumentation does not materially change behavior or overwhelm
  telemetry systems.
