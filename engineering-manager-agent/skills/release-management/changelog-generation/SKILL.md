# Changelog Generation

Gather merged changes and verified release metadata from the canonical sources.
Group entries by user impact (features, fixes, changes, and known issues), use
clear language, and omit internal implementation details that do not help the
audience. Verify versions, links, compatibility notes, and security disclosures
with their owners before publishing.
