# Pipeline Monitoring

Track the correct pipeline run, revision, stage, and environment. Distinguish
queued, running, failed, and successful states using run evidence. For failures,
capture the failing stage and actionable log details, notify the owner, and
follow the established retry or incident process. Do not retry blindly or
promote artifacts without verified provenance.
