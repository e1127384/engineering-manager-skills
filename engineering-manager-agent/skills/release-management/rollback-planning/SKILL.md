# Rollback Planning

Define rollback triggers, decision authority, target known-good version, exact
recovery steps, expected duration, and validation criteria. Assess database,
configuration, and data compatibility; a binary rollback may not reverse
irreversible changes. Document communication and escalation paths, and rehearse
or validate the plan when practical. Execute only through approved procedures.
