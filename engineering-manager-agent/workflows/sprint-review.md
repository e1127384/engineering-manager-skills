# Sprint Review Workflow

1. Confirm the sprint goal, participants, and source work items.
2. Review completed outcomes using working software or other direct evidence.
3. Identify unfinished work and explain status changes without assigning blame.
4. Capture stakeholder feedback, decisions, risks, and follow-up owners.
5. Update the backlog and share a concise summary with the team.

Do not treat incomplete scope as completed or infer progress from activity alone.
