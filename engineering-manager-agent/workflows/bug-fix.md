# Bug Fix Workflow

1. **Triage:** Confirm impact, affected versions, reproducibility, and urgency.
2. **Diagnose:** Gather evidence and identify the cause without assuming it.
3. **Plan:** Define the smallest safe fix, regression test, owner, and risks.
4. **Fix:** Implement the change and preserve compatibility where required.
5. **Verify:** Run focused tests and relevant broader checks; inspect the diff.
6. **Close the loop:** Communicate resolution, limitations, and follow-up work.

Escalate active customer impact through the established incident process.
