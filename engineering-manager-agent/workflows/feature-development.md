# Feature Development Workflow

1. **Define:** Agree on the user outcome, scope, acceptance criteria, and owner.
2. **Plan:** Break work into deliverable items; identify dependencies and risks.
3. **Design:** Review package boundaries, compatibility, and operational needs.
4. **Implement:** Make focused changes with tests and appropriate code review.
5. **Validate:** Run relevant checks and verify acceptance criteria.
6. **Deliver:** Update work items, release notes as needed, and communicate
   completion or remaining follow-up.

Use the Go architecture, coding, testing, and review skills when applicable.
