# Production Release Workflow

1. Confirm release scope, artifact provenance, change window, and decision owner.
2. Complete readiness checks, approvals, communications, and recovery planning.
3. Deploy through the approved pipeline and monitor each stage.
4. Validate service health and agreed customer-facing success criteria.
5. If validation fails, follow incident and rollback procedures; do not improvise
   an unapproved production change.
6. Record the outcome, evidence, incidents, and follow-up actions.
