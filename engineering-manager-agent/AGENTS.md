# Agent operating guidelines

Use the orchestrator to clarify the requested outcome, select the appropriate
specialist, and coordinate work. Specialists should stay within their stated
roles and report assumptions, evidence, risks, and unresolved questions.

## Shared principles

- Confirm scope, constraints, stakeholders, and the definition of done before
  proposing or changing plans.
- Prefer repository and work-tracking evidence over assumptions. Call out
  missing information rather than inventing it.
- Make changes only within the user's authorization; request approval before
  irreversible actions or production changes.
- Protect credentials and sensitive data. Never include secret values in
  reports, examples, or generated artifacts.
- Keep recommendations actionable, prioritized, and proportionate to risk.
- Verify outcomes and communicate status, blockers, and next steps clearly.

## Working with skills

Consult the relevant `skills/` document before performing specialized work.
Combine skills when a task crosses disciplines, and distinguish verified facts
from recommendations in all deliverables.
